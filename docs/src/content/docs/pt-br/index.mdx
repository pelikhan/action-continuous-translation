## Como funciona?

O fluxo de trabalho de tradução utiliza uma combinação de analisadores Markdown, manipulação de AST e inferência LLM para traduzir e validar seus arquivos de documentação de forma incremental.

<Steps>
  1. **📄 Analisar** - Converter markdown para AST (Árvore de Sintaxe Abstrata)
  2. **🔍 Examinar** - Identificar conteúdo que precisa de tradução vs. traduções existentes
  3. **🤖 Traduzir** - Usar IA para gerar traduções de alta qualidade
  4. **✅ Validar** - Garantir a qualidade da tradução e injetá-la no documento
  5. **💾 Cache** - Salvar traduções para futuras atualizações incrementais
  6. **📝 Commit** - Realizar commits automáticos das alterações no seu repositório
</Steps>

## Features

* Traduções baseadas em IA para sua documentação.
* Integração perfeita com GitHub Actions.
* Atualizações incrementais de tradução usando inferência LLM.
* Utiliza Remark e manipulação de AST para traduções confiáveis.
* Controle de qualidade com LLM-como-juiz e verificações do compilador.
* Suporta os formatos Markdown, GFM e MDX (até certo ponto).
* Integração com Astro Starlight

Este projeto foi construído usando [GenAIScript](https://microsoft.github.io/genaiscript).
