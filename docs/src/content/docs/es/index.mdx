## ¿Cómo funciona?

El flujo de trabajo de traducción utiliza una combinación de analizadores de Markdown, manipulación de AST e inferencia LLM para traducir y validar tus archivos de documentación de manera incremental.

<Steps>
  1. **📄 Parsear** - Convierte markdown a AST (Árbol de Sintaxis Abstracta)
  2. **🔍 Analizar** - Identifica el contenido que necesita traducirse frente a las traducciones existentes
  3. **🤖 Traducir** - Usa IA para generar traducciones de alta calidad
  4. **✅ Validar** - Asegura la calidad de la traducción e inyecta en el documento
  5. **💾 Caché** - Guarda las traducciones para futuras actualizaciones incrementales
  6. **📝 Commit** - Realiza commits automáticos de los cambios en tu repositorio
</Steps>

## Features

* Traducciones impulsadas por IA para tu documentación.
* Integración perfecta con GitHub Actions.
* Actualizaciones de traducción incremental utilizando inferencia LLM.
* Utiliza Remark y manipulación AST para traducciones fiables.
* Control de calidad con LLM-como-juez y verificaciones de compilador.
* Admite formatos Markdown, GFM y MDX (hasta cierto punto).
* Integración con Astro Starlight

Este proyecto está construido utilizando [GenAIScript](https://microsoft.github.io/genaiscript).
